# PWM Generator Using Verilog

## 📌 Project Overview

This project implements a Pulse Width Modulation (PWM) Generator using Verilog HDL.

PWM is a technique used to control the average power delivered to an electronic device by changing the duty cycle of a digital signal.

The PWM generator in this project uses an 8-bit counter and an adjustable 8-bit duty-cycle input.

## 🎯 Objective

The objective of this project is to design and simulate a PWM Generator using Verilog HDL and verify different duty-cycle values through simulation.

## ⚙️ Features

* Clock-driven PWM generation
* Reset functionality
* Adjustable duty cycle
* 8-bit resolution
* Supports approximately 0% to 100% duty cycle
* Testbench for functional verification
* VCD waveform generation

## 🧩 Inputs and Outputs

### Inputs

* `clk` – System clock
* `reset` – Reset signal
* `duty_cycle[7:0]` – Controls the PWM duty cycle

### Output

* `pwm_out` – PWM output signal

## 🔢 Working Principle

An 8-bit counter continuously counts from 0 to 255.

The PWM output is generated by comparing the counter value with the duty-cycle value.

```text
If counter < duty_cycle
    pwm_out = 1

Otherwise
    pwm_out = 0
```

For example:

* Duty cycle = 64 → approximately 25%
* Duty cycle = 128 → 50%
* Duty cycle = 192 → 75%

The PWM period consists of 256 clock cycles.

## 🛠️ Tools Used

* Verilog HDL
* Icarus Verilog
* GTKWave
* ModelSim or Vivado
* Visual Studio Code

## ▶️ How to Run

Compile the Verilog files:

```bash
iverilog -o pwm_sim pwm_generator.v pwm_generator_tb.v
```

Run the simulation:

```bash
vvp pwm_sim
```

Open the waveform:

```bash
gtkwave waveform.vcd
```

## 📊 Applications

PWM generators are commonly used in:

* Motor speed control

* Power electronics
* DC-DC converters
* Servo motor control
* Audio applications

## ⚠️ Note

The PWM frequency depends on the system clock frequency and the counter resolution.

For an 8-bit PWM generator:

```text
PWM Frequency = Clock Frequency / 256
```
